# Tumble trailer

**[tumble-trailer.mp4](tumble-trailer.mp4)**: 83 seconds, 1920×1080, 30 fps.

Steve takes a nice walk to a cave, a creeper sends him all the way to the bottom of it,
and he comes back for his stuff. A montage covers the rest of the mod: lightning, elytra
crashes, going limp on command, mob bodies and dragging them around.

The planning, research and full shot list are in [PRODUCTION.md](PRODUCTION.md).

## What is real in it

| | |
|---|---|
| World | Generated by the vanilla 1.20.1 server (seed `8091867987493326313`) and read straight from its region files. The set is a natural cave entrance at x 1500, z 139. |
| Blocks | Every block state is baked from the client jar's own blockstate and model JSON, with biome tints, animated textures, cullfaces, and vanilla smooth lighting from the saved sky and block light. |
| Entities | Steve, the creeper, the zombie and the elytra use vanilla model geometry, box UVs, animation formulas and render transforms. |
| Ragdolls | Every body is simulated by Tumble's own solver, unchanged (`src/main/java/.../physics` and `RagdollSkeleton`), at 20 TPS with the mod's default config. Launches use the mod's trigger formulas (explosion, lightning, elytra crash, manual), and grab, roll and impact damage follow `RagdollEntity`. |
| The fall | The creeper's crater is vanilla's `Explosion.explode()` ray march with real blast resistances. The hits that hurt are the mod's impact damage, and Steve dies on the last one at 8.8 s. The death message is the game's own string for that damage type. |
| UI | The HUD, death screen, chest screen and chat are drawn from the game's GUI textures and bitmap font, at vanilla's coordinates and GUI scale. |
| Sound | All effects are game sounds. The score is original, sequenced from note block samples at their real pitches. |

Mojang's assets are never committed: the pipeline downloads them from Mojang when it
runs, as their usage guidelines allow for videos.

## Layout

```
world/      Anvil reader, block model baker, mesher, crater, set dressing,
            location scouting, path planning, simulation scenarios
physics/    TrailerSim.java: drives Tumble's solver against the real world
render/     three.js renderer run in Chromium (Mesa llvmpipe under Xvfb):
            terrain, sky, entities, particles, weather, camera solver, overlays,
            post effects and the timeline itself (render/js/shots.js)
audio/      sound fetcher, score (note blocks) and mixer
tools/      fetch Minecraft, generate the world, run everything, encode
```

## Rebuilding it

```sh
ACCEPT_MINECRAFT_EULA=1 trailer/tools/run_all.sh trailer/tumble-trailer.mp4
```

This needs JDK 17+, Python 3 with numpy, scipy and pillow, Node 18+ with Playwright and
its Chromium, Xvfb and ffmpeg. It runs Mojang's dedicated server to generate the world,
which means accepting the [Minecraft EULA](https://aka.ms/MinecraftEULA). A full render
is about 0.7 s per frame at 1080p on four CPU cores, with no GPU.

Every frame depends only on its own timestamp, so one shot can be re-rendered without
re-rendering the rest:

```sh
cd trailer/render
xvfb-run -a node render.js --out FRAMES_DIR --from 26.5 --to 35.3
```

`render/audit.js FROM TO` reports any frame whose camera sits inside terrain.
`render/scout.js` renders stills from arbitrary camera positions, for location work.

## Things the trailer surfaced about the mod

The trailer shows the mod as it behaves, so it ran into a few rough edges:

- **Dying while ragdolled resets the body's pose.** `CorpseHandler` ends the ragdoll and
  `CorpseEntity.of` builds a new skeleton from `LimbPose.of(player)` at the player's
  position, which is the old body's centre of mass. The crumpled body pops back to a
  standing pose and falls over again. The trailer cuts to the death screen on that frame.
- **Elytra crashes start upright.** `LimbPose` covers walking, crouching and head look
  but not fall flying, so a body that was horizontal when it hit spawns standing. Copying
  the flight pitch into the skeleton's initial orientation would fix it.
- **Zombie arms drop at death.** Mob corpses start from the walk cycle, so a zombie's
  raised arms snap down on the death frame.
- **Ragdolls ignore water.** The falling body passes straight into the cave's aquifer,
  because the collider only knows solid blocks.
